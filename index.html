State News — Elementor Kit Documentation

Complete setup and customization guide for the State News kit: a regional / state-level news portal design with a live clock header, Hindi news ticker, category-wise loop grids, load-more blocks, ad slots, a search popup and a fixed “join us on WhatsApp” button. Everything is built in Elementor — no coding required.

✔ Elementor Pro kit ✔ 14 templates ✔ 20 demo posts Hello Elementor 3.4.4 Elementor 3.30.3+ Elementor Pro 3.29.2 / 4.3.1 PHP 7.4+

1Overview

What this kit is, who it is for, and how it is built.

State News is a complete Elementor Pro website kit for state-level and local news portals, district update sites, YouTube news channels and small newsrooms. You do not build page by page — you import one ZIP file and the design, the demo posts, the menus and the Theme Builder layouts (header, footer, single post, archive, 404, search popup) all arrive ready.

Design at a glance

  • Header — top strip with a live date + clock (JavaScript clock, updates every second), “follow us” text and social icons; main row with logo, main menu, YouTube and e-paper buttons; a second menu row below the header.
  • Home — Hindi news ticker, then category-wise news sections (आज की ताजा ख़बर, टॉप 10 ख़बरें, मनोरंजन, राजनीति, मध्यप्रदेश, राज्य, टॉप 3 ख़बरें…) built with Loop Grid widgets, plus dedicated ad slots.
  • Single post — title, author/date/time meta, featured image, content, share buttons, post navigation, “must read” sidebar, related posts and a WhatsApp “join us” button.
  • Archive & search — full-width card grid with archive title; 404 page and a search popup with live results.
  • Footer — icon menu (home, trending, location, videos, tv), GTranslate language switcher, back-to-top and copyright bar.

Version pairing

The kit was exported on Elementor 3.30.3 + Elementor Pro 3.29.2. The Pro ZIP bundled in this download is 4.3.1, which requires a matching Elementor core (4.x). Both routes work:

  • Fresh site (recommended): install the latest Elementor free + the bundled Pro 4.3.1, then import the kit. Templates import cleanly on 4.x.
  • Existing site on Elementor 3.x: keep your current Pro version and do not install Pro 4.3.1 until you also update Elementor core — mismatched core/Pro versions break the editor.
After the import, open Elementor → Tools → Regenerate CSS & Data once. This rebuilds the stylesheet for the new global colours and typography and fixes “design looks slightly off” issues.

4Before you start

Five minutes of preparation saves an hour of troubleshooting.

  1. Take a backup — database + wp-content (UpdraftPlus, All-in-One WP Migration or your host’s one-click backup). The kit import adds content; it never deletes your existing pages, but a backup is always cheaper than a repair.
  2. Use a clean site if possible — a new WordPress install with only Hello Elementor, Elementor, Elementor Pro and the two bundled plugins. Other page builders (WPBakery, Divi) and aggressive optimization plugins can interfere with the Elementor editor.
  3. Raise the server limits — ask your host for memory 256 MB, upload 64 MB, execution 300 s. On cPanel you can often do it yourself in MultiPHP INI Editor: 
    memory_limit = 256M
upload_max_filesize = 64M
post_max_size = 64M
max_execution_time = 300
  4. Turn off caching/optimization plugins while you import and design (LiteSpeed Cache, WP Rocket, Autoptimize, Cloudflare “Rocket Loader”). Re-enable them at the end and purge.
  5. Keep Elementor in Safe Mode off — if the editor already misbehaves, first check Elementor → Tools → Safe Mode to see whether a plugin is the cause.
Staging tip: import on a sub-domain or staging copy first (e.g. staging.yoursite.com). When every section looks right, migrate to the live domain. Elementor stores absolute URLs in some widgets (logo links, ad images) — after migration run Better Search Replace or Elementor → Tools → Replace URL.

5Step-by-step installation

From a blank WordPress to a working State News site — about 15 minutes.

Installation order — theme first, plugins second, kit last. Do not skip step 3: without the ticker plugin the Hindi ticker bar stays empty.

  1. Install and activate Hello Elementor
    Appearance → Themes → Add New → Upload Theme → hello-elementor.3.4.4.zip → Install → Activate
    Any Elementor-ready theme works, but the kit’s header/footer are built with Hello’s canvas in mind — use Hello to get the same result as the preview.
  2. Install Elementor (free)
    Plugins → Add New → search “Elementor Website Builder” → Install → Activate
    Skip Elementor’s onboarding wizard (close it) — the kit brings its own settings.
  3. Install Elementor Pro
    Plugins → Add New → Upload Plugin → elementor-pro.zip → Install → Activate
    Then open Elementor → License and connect/activate your license if you have one, so Pro updates and the template library work.
  4. Install the two required plugins
    Plugins → Add New → Upload Plugin → pj-news-ticker.zip → Activate
    Plugins → Add New → Upload Plugin → gtranslate.3.0.9.zip → Activate
    PJ News Ticker powers the scrolling Hindi headline bar on the homepage. GTranslate powers the language dropdown in the footer. Without them you will see an empty ticker and an empty footer slot — both are shortcodes, so nothing breaks, it just stays blank.
  5. Import the kit
    Elementor → Tools → Import / Export → “Import Kit” tab → Choose file → State news kit.zip → Import
    When the progress screen appears, leave all three checkboxes ticked:
    • Site Settings — global colours, typography, layout, Hello header/footer behaviour
    • Templates — header, footer, single post, archive, 404, search popup, 8 loop items
    • Content — homepage, 20 demo posts, 3 menus, 9 categories
    Click Next → Import and wait. A 20-post kit usually finishes in 30–90 seconds. Do not close the tab — if the browser tab sleeps, the import can stop halfway.
  6. Verify the Theme Builder conditions
    Templates → Theme Builder
    You should see Header, Footer, Single Post, Archive, 404 and the Search popup already listed with their conditions (section 6 lists them all). If a template shows “No condition”, open it → Settings → add the condition from the table.
  7. Check the homepage and menus
    Settings → Reading → “Your homepage displays” = A static page → Home
    Then Appearance → Menus and confirm the three menus are assigned: Main menu, Hdr and Below 👇 header Menu. (The header template has two Nav Menu widgets, one per location.)
  8. Make it yours Logo, colours, fonts, ticker text, ad banners, WhatsApp link and the copyright line — all covered in section 9. Finally: Elementor → Tools → Regenerate CSS & Data, then purge your cache.
The “import stops at 60%” problem. If the progress bar freezes, refresh the page and check what actually arrived (Elements → Templates). Then fix the limits from section 4 and run the import again — a second import is safe: existing templates are overwritten by ID, not duplicated. On very low-budget hosting, import on a local install (LocalWP / XAMPP) and migrate the finished site instead.

9Customization cookbook

Twelve common changes, each with the exact path and settings.

9.1 · Logo

Site Settings (top-left of the Elementor editor) → Site Identity → Site Logo → upload your PNG/SVG → publish. Recommended size: 240 × 60 px (transparent PNG, 2× for retina). The header uses the Site Logo widget, so the change applies everywhere at once.

9.2 · Colours

Site Settings → Global Colors. Edit the four system colours (Primary #222222, Secondary #001A39, Text #333333, Accent #12BF2A) and the three custom ones (meta #888888, red #DD3333, asst #51A1D6). Every widget that uses a global colour updates instantly — no per-widget editing.

Keep the red token for breaking-news labels and the Accent for CTAs. If you change the Accent to your brand colour, the “join us” and ticker highlights follow automatically.

9.3 · Fonts

Site Settings → Global Fonts → change Primary / Secondary / Text / Accent. For Hindi + English sites, a Devanagari-capable family (Noto Sans Devanagari, Mukta, Hind, Poppins + Noto) keeps headlines clean. Per-widget overrides live in Style tabs and always beat global styles.

9.4 · Menus

MenuLocation used byWhat to put in it
main-menuHeader main row (Nav Menu widget)6–8 primary sections: Home, राज्य, देश, मनोरंजन, खेल, टेक, वीडियो

Edit at Appearance → Menus, then refresh the header canvas. To rename a location: header template → click the Nav Menu widget → Content → Menu.

9.5 · Ad slots

The kit has three monetization spots: two “ads” sections on the homepage (banner rows between news blocks) and one sidebar ad in the single-post template (the demo image is titled “Election ad”).

  1. Open the template/page in Elementor, click the ad Image widget.
  2. Content → Choose Image → upload your banner, then Link → your advertiser URL (set nofollow if required).
  3. Sizes that fit the layout: 728 × 90 or 970 × 250 for the homepage banners, 300 × 250 or 300 × 600 for the sidebar.
  4. Selling ads through a network? Drop an HTML widget in place of the image and paste the network’s ad code (AdSense / Adsterra / Ezoic).
  5. Not monetizing yet? Delete the image and the section collapses — or hide it while you build traffic.

9.6 · YouTube, e-paper and WhatsApp links

All three are ordinary widgets — update the link and you’re done:

  • YouTube button — header template → Icon Box “YouTube” → Content → Link → https://youtube.com/@yourchannel.
  • e-paper button — same widget type, link to your PDF flipbook or e-paper page.
  • WhatsApp button — single-post template → Button “join us” → Link → https://chat.whatsapp.com/XXXXXXXXXXX (group) or https://wa.me/91XXXXXXXXXX (direct chat). Keep target = _blank.
  • Social icons (header strip) — click the Social Icons widget → edit each item’s link and icon.

9.7 · Category sections (Loop Grid)

Click any Loop Grid → Content:

  • Query → Source: Posts. Include → By term: pick your category (e.g. राज्य), then remove the demo category.
  • Layout: Columns (per device), Posts per page (6–12 is a good homepage block).
  • Pagination: Load More (recommended) · Numbers · Previous/Next · None.
  • Loop item: the design of each card — switch between card, story, thumb t list, Simple grid, POST TITLE ONLY.
Loop items are shared. Editing “card” changes every grid using “card”. To restyle one section only, duplicate the loop item (Templates → Loop Items → Duplicate), rename it, and point that grid at the copy.

9.8 · Header layout tweaks

  • Sticky header — click the header container → Advanced → Motion Effects → Sticky → Top → set “Sticky on” = all devices. Add a white background + shadow in Style so text stays readable.
  • Hide the clock — select the HTML widget → Advanced → Responsive → Hide on…, or delete the widget entirely.
  • Smaller header on mobile — the Nav Menu widget has a mobile toggle; style it under Style → Mobile Menu (colour, width, icon).

9.9 · Footer

  • Quick links — six Icon Boxes: home, trending, location, videos, tv, top. Change the label, icon (Font Awesome) and link.
  • Language switcher — the [gtranslate] shortcode widget (see section 11).
  • Copyright — heading widget “©️ 2024 Today’s Public…” → replace with your name and year, or set it once under Site Settings → Settings → Footer copyright.
  • Back to top — the “Top” icon box links to #; keep it and add smooth scrolling with the CSS in section 15.

9.10 · Search popup

Templates → Popup → Search → Edit with Elementor. The popup contains a Search widget (post type: Post) and a hint heading. Under Settings → Conditions it should be triggered by the header icon; check the trigger under Settings → Triggers (click / on-page load). Style the overlay in Style → Overlay.

9.11 · 404 page

Templates → Theme Builder → 404 page look. Edit the message, image and the “Go to home” button link. Condition should stay 404 page.

9.12 · Site icon, title and tagline

Settings → General for the site title/tagline (used in SEO titles), and Site Settings → Site Identity → Site Icon for the browser-tab favicon (512 × 512 px).

The Hindi headline bar is powered by PJ News Ticker.

Default usage (what the kit puts at the top of the homepage):

[pj-news-ticker]

Customised — the most useful parameters:

[pj-news-ticker
  num_posts="6"
  post_cat="rajya,desh"
  show_label="true"
  label_text="ताज़ा ख़बर"
  label_bg_colour="#DD3333"
  label_text_colour="#ffffff"
  ticker_bg_colour="#ffffff"

  size="16px"
  target="_blank"
  hide_if_empty="true"]
AttributeDefaultWhat it does
num_posts5How many posts scroll (-1 = all matching)
post_cat0 (all)Category slugs, comma-separated. Never point it at an empty category — the bar then shows nothing
show_label / label_texttrue / “Latest Posts”The fixed label chip before the scrolling text
label_bg_colour / label_text_colour#1e73be / #ffffffLabel colours

11Bundled plugins

Two small plugins complete the design — here is what each one needs.

11.1 · PJ News Ticker GPL

  • Install: Plugins → Add New → Upload → pj-news-ticker.zip → Activate.
  • Settings: Settings → PJ News Ticker for site-wide defaults.
  • Use: shortcode anywhere — inside Elementor with a Shortcode widget, in a Text widget, or in a template.
  • Troubleshooting: empty bar → the category slug in post_cat has no posts, or you have fewer posts than num_posts.

11.2 · GTranslate Free tier + paid cloud

  • Install: Plugins → Add New → Upload → gtranslate.3.0.9.zip → Activate.
  • Where it appears: the footer of the kit uses the shortcode widget with [gtranslate] — so the switcher shows in the footer without touching a widget area.
  • Configure: Settings → GTranslate → choose the widget look (dropdown / flags / floating), the languages you need, and whether translation is free (Google’s auto translate) or the paid cloud version (better SEO, separate indexed URLs).
  • Manual text: for a Hindi-first site, type your headlines in Hindi and offer English (and other languages) through GTranslate; machine translation is good enough for headlines and improves with the paid tier.
GTranslate injects its script from Google’s servers. If your site is behind a strict Content-Security-Policy or an aggressive script-blocker, allow translate.google.com / cdn.gtranslate.net or the switcher will stay invisible.

12Managing demo content

Turning the demo into a real news site.

  1. Rename categories first — Posts → Categories. Replace demo names (News, 5g, Ai, Space, label2…) with your real sections (राज्य, देश, मनोरंजन, खेल…). Slugs matter if you use the ticker’s post_cat. Then update each homepage Loop Grid’s query to the new category.
  2. Write 3–5 real posts before deleting the demo — layout gaps look worse than placeholder text. Publish into the right categories so every section stays filled.
  3. Delete the demo posts — Posts → tick Select All (they all start with the demo titles) → Bulk actions → Move to Trash. Your own posts stay because they were unselected. Empty the trash afterwards.
  4. Featured images — every card depends on the featured image. Use 1200 × 675 px (16:9), JPEG, under ~250 KB. Set them from the post editor’s Featured image box, or bulk-set with a plugin if you migrate old articles.
  5. Update the menus — Appearance → Menus → add your categories. Use one top-level item per section and keep child items for districts.
  6. Set the homepage — Settings → Reading → static page → Home (already done by the kit). If you built a new homepage, point Reading at it.
  7. Permalinks — Settings → Permalinks → Post name → Save. Clean URLs like /your-article-slug/ are better for news SEO and ad networks.
  8. Author box — create real author accounts (Users → Add New) with display names and bios; the Post Info widget shows the author automatically.
Bulk import old articles? Export them from your previous site (Tools → Export) and import here (Tools → Import → WordPress). Tick “Download and import file attachments” so featured images come along, then run Tools → Regenerate thumbnails.

13Performance & SEO checklist

A news site lives on repeat visits and Google News — these settings pay off fastest.

Speed

  • Keep Hello Elementor — it is the lightest Elementor theme.
  • Turn on Elementor → Settings → Features → Optimized Assets / Improved CSS Loading (fetch styles only where needed).
  • Compress images (WebP + lazy load). Cap homepage featured images at 1200 × 675 px.
  • Limit homepage Loop Grids to 6–12 posts each; they multiply fast.
  • Use one caching layer only (LiteSpeed Cache or WP Rocket or host cache) and purge after design changes.
  • Add a CDN (Cloudflare free tier) for repeat readers across states.
  • Elementor → Tools → Regenerate CSS after big edits; delete unused templates.

SEO

  • Settings → Permalinks → Post name.
  • Install an SEO plugin (Rank Math / Yoast / SEOPress) and connect Google Search Console.
  • Use one H1 per page: the Post Title widget already outputs H1 on single posts — keep section headings at H2/H3.
  • Fill category titles + descriptions (they power archive titles).
  • Add a sitemap and submit it; enable News sitemap if you have a Google News policy page.
  • Keep 1200×675 featured images — they become the OpenGraph / Twitter card image.
  • Author pages with real names build E-E-A-T for news content.

14Troubleshooting & FAQ

Every issue we have seen on a kit install, with the fix.

The kit import freezes or stops halfway (“Importing…” never finishes)
  1. Raise memory_limit to 256 MB, max_execution_time to 300 s, upload_max_filesize / post_max_size to 64 MB.
  2. Turn off caching, security and optimization plugins for the duration of the import.
  3. Import only what you need: untick Content to import just templates + settings (much lighter).
  4. Still failing? Import locally (LocalWP / XAMPP), then migrate with All-in-One WP Migration.
Import finished but the homepage is blank / shows the blog index
Go to Settings → Reading → “Your homepage displays” = A static page → choose Home. Then Settings → Permalinks → Save (this flushes rewrite rules). If the page exists but looks unstyled, run Elementor → Tools → Regenerate CSS & Data.
Loop grids are empty or show “requires Elementor Pro”
Elementor Pro is not active, or core and Pro versions do not match. Activate Pro under Plugins, and make sure Elementor core is 4.x if you installed the bundled Pro 4.3.1 (Pro 4.x needs Elementor 4.x). After fixing, open one grid and click Update.
Header / footer / single post design is not applied to the site
Check the conditions: Templates → Theme Builder → each template should show Entire site (header/footer) or All singular posts / All archives. If it says “No condition”, open the template → Settings (bottom-left) → Conditions → add. Conflicts appear as “Conditions: 2 templates match” — Elementor shows the one with higher priority; delete the leftover.
The Hindi news ticker is empty
Either PJ News Ticker is inactive, or the shortcode points at a category with no posts. Open the Shortcode widget on the homepage, replace post_cat="…" with a category slug that has published posts, or drop the attribute to show all posts. Also set hide_if_empty="false" while debugging so you can see the empty bar.
The GTranslate flag/dropdown does not appear in the footer
Activate the GTranslate plugin, then open Settings → GTranslate and pick a widget look (dropdown / flags). If it is still invisible, an optimization plugin may be deferring its script — exclude GTranslate and translate.google.com from “delay JS” / CSP rules, then purge cache.
Icons (YouTube, WhatsApp, footer icons) show as empty squares
Icons come from Font Awesome. In Elementor → Settings → Advanced, enable Load Font Awesome 4 Support (the kit uses fab fa-… classes) and make sure “Inline Font Icons” is off if your icons look broken. Then regenerate CSS. If you use the free Elementor Font Awesome 6 library only, pick the FA6 equivalent icon for each button.
Images are missing or blurry after the import
Demo image files are downloaded from the kit’s source site during import — if that request failed, images stay external. Re-upload your own featured images (1200×675), then install “Regenerate Thumbnails” and run it once so all card sizes exist.
The Elementor editor is slow or the panel never loads
  • Elementor → Tools → Safe Mode to isolate a plugin conflict.
  • Disable “Loading animation”/heavy effects while designing, add them back at the end.
  • Ask the host to raise PHP memory to 256 MB and set max_input_vars to 5000 (big Elementor pages fail to save otherwise).
  • Try a different browser/profile — ad-blockers and privacy extensions sometimes break the editor’s REST calls.
Can I use this kit on more than one site?
The license covers the number of sites you bought for. Elementor Pro is a separate subscription from Elementor — activate it on your own domain. To reuse the design on a second site, export the templates you need (Templates → Saved Templates → Export) rather than copying Elementor Pro to other people.
How do I move the site to another domain later?
Migrate with a plugin (All-in-One WP Migration / Duplicator), then fix absolute URLs: Better Search Replace for old→new domain, and Elementor → Tools → Replace URL. Re-save Settings → Permalinks and regenerate CSS. Logo, ad images and button links that used absolute URLs are the usual leftovers — check the header and ad widgets.
Can I change the design completely?
Yes — the kit is only a starting point. Global colours and fonts rebrand it in minutes; Theme Builder templates and loop items let you rebuild any block. Nothing is locked or encoded, and no shortcode depends on the kit itself.
